direction. Changes are limited to the Phase 1 frontend, its focused tests, and its
documentation:

- `apps/web/src/App.tsx`: rebuilt the editorial hierarchy, navigation, illustrated concept

- `apps/web/src/App.test.tsx`: updated visible expectations and added synthetic-example,

## Liquid lens redesign

The sculptural pass is superseded. The frontend was rebuilt around a WebGL lens, bundled
typefaces and scroll choreography; the API, contract, database and container settings are
untouched. `apps/web/src/ClaritySculpture.tsx` was deleted.

Added:

- `apps/web/src/lens.ts`: the hero bead. A ray-marched signed-distance shader on a
  transparent canvas above the headline; the headline is mirrored into a mask texture and
  magnified through the bead with a slightly different refraction per colour channel.
  Handles pointer attraction, context loss, resizing, an adaptive resolution step, and a
  single still frame when motion is off. Returns nothing on a software renderer. It asks
  for WebGL 2 first, links its shader without blocking the page, warms the pipeline up
  with a discarded draw, and reports when it is ready (D22).
- `apps/web/src/motion.ts`: scroll-linked progress values, entrance reveals, marquee rate,
  navigation dock, cursor follower and magnetic controls. Runs only while motion is on.
- `apps/web/src/boot.ts` and the static preloader in `apps/web/index.html`: the intro
  counter, lifted once the bundled fonts are usable and the hero has reported its lens
  ready, within a fixed limit and with a CSS failsafe. A reload in the same tab skips the
  counter and only wipes.
- `apps/web/src/boot.test.ts`: two unit tests for that wait and its limit.
- `apps/web/src/Hero.tsx`, `Idea.tsx`, `Playground.tsx`, `Roadmap.tsx`, `ui.tsx`,
  `types.ts`: the page split into sections; `App.tsx` keeps state and data loading.
  `ui.tsx` also draws the film grain from one small generated tile.
- `apps/web/src/fonts.css`: `@font-face` rules for the three bundled Latin subsets.
- `tests/e2e/review.mjs`: optional capture script for visual review in Chromium, WebKit or
  Firefox; not part of the gate. Its entrance scene steps the page's animation clock, so
  the bead's entrance can be captured and measured frame by frame on a slow rasteriser.

Changed:

- `apps/web/src/styles.css`: rewritten for the new design system and its fallbacks.
- `apps/web/src/App.tsx`: now also records when the status check ran and how long the
  round trip took, shown in the engine panel.
- `apps/web/package.json` and `package-lock.json`: three pinned `@fontsource` packages
  (Bricolage Grotesque, Instrument Serif, Geist Mono; OFL-1.1), installed with the
  containerized npm. No JavaScript dependency was added.
- `apps/web/vite.config.ts`: assets are never inlined, so fonts satisfy the existing CSP.
- `apps/web/src/App.test.tsx` and `tests/e2e/smoke.spec.ts`: expectations for the new
  page; the browser suite gained a lens pixel check, scroll-choreography assertions and a
  navigation-fit check, and now has six tests.
- `tests/e2e/playwright.config.ts`: failure traces keep the action log only, and the
  per-test bound is 60 seconds (D21).
- `README.md`, `docs/DECISIONS.md` (D18-D22), `docs/THREAT_MODEL.md`, `docs/PLAN.md`,
  `docs/EVIDENCE.md`, and this inventory.

Review captures live in `artifacts/ui-review`; the gate's own screenshots stay in
