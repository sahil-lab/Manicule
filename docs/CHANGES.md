`artifacts/e2e/dashboard.png`; details are recorded in `docs/EVIDENCE.md`.

## Sculptural UI redesign

The previous cinematic pass is superseded by an original charcoal-and-citrus visual
direction. Changes are limited to the Phase 1 frontend, its focused tests, and its
documentation:

- `apps/web/src/App.tsx`: rebuilt the editorial hierarchy, navigation, illustrated concept
  section, live workspace, native roadmap disclosures, and oversized footer. Added an
  explicit motion control and reduced-motion handling, a keyboard skip link, and a
  synthetic-example form action. Inputs are disabled while validation is pending; editing
  metadata clears stale success as well as error feedback.
- `apps/web/src/ClaritySculpture.tsx`: original, locally calculated and shaded SVG
  sculpture. Its static mesh is memoized; mouse movement transforms the overall surface,
  while a native slider supports keyboard rotation. No external asset or dependency.
- `apps/web/src/styles.css`: replaced the old visual system, corrected the unmatched
  hero-headline selector, added responsive composition, native scroll-linked movement,
  focus treatments, and reduced-motion/paused states.
- `apps/web/index.html`: aligned the browser theme color with the new design.
- `apps/web/src/App.test.tsx`: updated visible expectations and added synthetic-example,
  pending-input, and stale-result coverage.
- `tests/e2e/smoke.spec.ts`: retained real validation and API checks; added measured
  headline sizing, actual text-bound checks, keyboard navigation, motion controls, roadmap
  disclosure, and responsive checks from 320 px to 1440 px.
- `README.md`, `docs/PLAN.md`, and `docs/EVIDENCE.md`: current experience, phase status,
  commands, and verification evidence.

Screenshots are generated by the real Chromium tests in `artifacts/e2e`: `dashboard.png`,
`hero-desktop.png`, `hero-mobile.png`, and `workspace-mobile.png`. Backend source, API
contracts, dependency manifests, and container resource/isolation settings are unchanged.
